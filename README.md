# Spring Boot Authentication Project

This project is a Java application built with Spring Boot and Maven. It demonstrates authentication using Spring Security.

## Features

- Spring Boot application structure
- Custom `AuthenticationProvider` implementation
- Maven-based build and dependency management

## Requirements

- Java 17 or higher
- Maven 3.6+
- IntelliJ IDEA (recommended)

## Getting Started

1. **Clone the repository:**
git clone <repository-url> cd <project-directory>

2. **Build the project:**
mvn clean install

3. **Run the application:**
mvn spring-boot:run


## Project Structure

- `src/main/java` - Application source code
- `src/test/java` - Unit and integration tests
- `pom.xml` - Maven configuration

## Custom Authentication

The project uses a custom implementation of Spring Security's `AuthenticationProvider` interface for authentication logic.
